01 · Account

Create a free GitHub account

  1. Open github.com/signup.
  2. Use an email you can open right now.
  3. Free plan. That is enough.
02 · Repo

Create a normal repo

  1. Open github.com/new. You must be signed in.
  2. Name it github-setup-hour.
  3. Public is fine for tonight.
  4. Check Add a README file. That gives you a file to edit.
  5. Click Create repository.
03 · Clone

Clone it with your tool

  1. On the repo page, click the green Code button. Copy the HTTPS link.
  2. Open Claude Code, Codex, or whatever you already use.
  3. New agent. Paste the link. Say: hey, clone this repo for me locally.
  4. If you just made the account, stay on HTTPS. Do not use SSH unless you already have a key.
04 · Change and push

Open the folder in your tool

  1. New agent. Select the github-setup-hour folder.
  2. Paste the prompt below. If GitHub asks who you are, log in in the browser. Same account. Do not type a password in the terminal.
  3. Refresh the repo on github.com. Your line should be in README.md.
Open README.md. Add a short line at the top with my name and today's date that says this repo is the save point for the Product School GitHub setup hour. Commit that change and push it to GitHub.
